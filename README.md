# Conversor de Unidades

Un conversor de unidades interactivo y sencillo diseñado para realizar conversiones de manera rápida y eficiente entre distintas escalas de medición (como longitud, peso, temperatura, entre otras).

---

## 🚀 Características

* **Interfaz intuitiva:** Diseño sencillo e interactivo fácil de usar.
* **Conversión multicategoría:** Soporte para unidades de longitud, masa/peso, temperatura y más.
* **Resultados en tiempo real:** Cálculo inmediato al ingresar el valor.

---

## 🛠️ Tecnologías utilizadas

* **Lenguaje principal:** JavaScript / Python / HTML / CSS *(ajustar según el proyecto)*
* **Control de versiones:** Git & GitHub

---

## 📦 Instalación y uso

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/luu-rios/Cnvensor-de-unidades.git](https://github.com/luu-rios/Cnvensor-de-unidades.git)

```

2. **Acceder al directorio del proyecto:**
```bash
cd Cnvensor-de-unidades

```


3. **Ejecución:**
* Abrir el archivo `index.html` en el navegador *(o ejecutar el archivo script principal según el lenguaje usado)*.
